# Simply KISS

A concise Codex skill for writing simple, obvious, maintainable code with cohesive modules, explicit behavior, local changes, and refactor-safe tests.

## Install

Ask Codex:

```text
Use $skill-installer to install https://github.com/ioma8/simply-kiss.
```

## Use

```text
$simply-kiss review this module for unnecessary complexity.
$simply-kiss implement this feature with the simplest maintainable design.
```
